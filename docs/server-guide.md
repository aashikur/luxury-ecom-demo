# ⚡ Server Scaling & Traffic Calculation Guide

> **১ সেকেন্ড রিভিশন রুল:**  
> ই-কমার্সে গড় কনভার্সন রেট **২%** (প্রতি ১০০ জন ভিজিটরে ২টি অর্ডার হয়)।  
> $\text{ভিজিটর সংখ্যা} = \frac{\text{অর্ডারের সংখ্যা}}{০.০২}$

## ২. অর্ডারের সাথে ভিজিটরের হিসাব (The 2% Math)

* **১০টি অর্ডার পেতে:** ৫০০ জন ভিজিটর লাগে।
* **৫০টি অর্ডার পেতে:** ২,৫০০ জন ভিজিটর লাগে।
* **১০০টি অর্ডার পেতে:** ৫,০০০ জন ভিজিটর লাগে।
* **৫০০টি অর্ডার পেতে:** ২৫,০০০ জন ভিজিটর লাগে।

## ৩. ৩টি বাস্তবসম্মত সার্ভিস লেভেল (Level 1, 2, 3)

### 🟢 Level 1: The Bootstrap Store (০ – ৫০ অর্ডার / দিন)
* **টার্গেট:** নতুন ব্র্যান্ড বা স্টার্টআপ।
* **স্ট্যাক:** Vercel Free + Cloudflare Free CDN + Cloudflare R2 + MongoDB M0 Free।
* **মাসিক খরচ:** **\$0 (সম্পূর্ণ ফ্রি)**।
* **কেন চলবে?** Cloudflare এর ঢাকা PoP (Edge) থেকে স্ট্যাটিক পেজ ও R2 ইমেজ ক্যাশ হয়, ফলে Vercel-এর 100GB ফ্রি লিমিট কখনো ক্রস করে না।

### 🟡 Level 2: The Active Brand (৫০ – ২০০ অর্ডার / দিন)
* **টার্গেট:** নিয়মিত ফেসবুক অ্যাড চালানো ব্র্যান্ড (মাসিক সেলস ২০ – ৫০ লাখ টাকা)।
* **স্ট্যাক:** Vercel Pro (\$20) + MongoDB Flex (\$5-\$9) + Cloudflare R2।
* **মাসিক খরচ:** **~\$25 – \$29 / মাস (প্রায় ৩,০০০ – ৩,৫০০ টাকা)**।
* **কেন জরুরি?** দিনে ২০০ অর্ডারে ডাটাবেজে কনকারেন্ট রাইট বাড়ে। Mongo Flex-এ ১,৫০০ কানেকশন এবং ডেইলি অটো-ব্যাকআপ থাকায় ঈদের ক্যাম্পেইনেও সাইট ১ সেকেন্ডের জন্য ডাউন হবে না।

### 🔴 Level 3: The Mega Scale (২০০ – ১,০০০+ অর্ডার / দিন)
* **টার্গেট:** সুপার ব্র্যান্ড (মাসে কোটি টাকার সেলস)।
* **স্ট্যাক:** 
  * *Option A:* Vercel Pro + MongoDB M10 Dedicated Cluster + Upstash Redis (~**\$80/মাস**)।
  * *Option B:* Hetzner 8-Core Dedicated VPS (\$20/মাস) Docker standalone + Mongo Atlas।
* **মাসিক খরচ:** **\$40 – \$80 / মাস**।

## ৪. Cloudflare Edge CDN কীভাবে সার্ভারের ৭০%-৮৫% চাপ কমায়?

```text
[ ১০,০০০ ভিজিটর ] 
       │
       ▼
[ Cloudflare Free CDN (Dhaka Edge) ]
       │
       ├── ৮৫% ট্র্যাফিক (ছবি, CSS, JS, প্রোডাক্ট ক্যাশ) ➔ Cloudflare সরাসরি ডেলিভারি দেয়!
       │   (Vercel সার্ভার বা ডাটাবেজ এই ভিজিটরের চাপ টেরই পায় না!)
       │
       └── মাত্র ১৫% ট্র্যাফিক (চেকআউট বাটন ও অর্ডার সাবমিট) ➔ Vercel সার্ভারে পৌঁছায়।
```

## ৫. ফেইক অর্ডার ও বট আটকানোর কৌশল (Rate Limiting)
* **টুল:** Upstash Redis (`@upstash/ratelimit`) - ফ্রি টিয়ারে দিনে ১০,০০০ রিকোয়েস্ট ফ্রি।
* **রুল:** ১টি IP এড্রেস থেকে ১ মিনিটে সর্বোচ্চ ৫টি অর্ডারের বেশি সাবমিট করা যাবে না।
* **ফলাফল:** বট বা স্প্যামাররা ইচ্ছাকৃত ফেইক অর্ডার পাঠিয়ে সার্ভার বা ডাটাবেজ ডাউন করতে পারবে না (`429 Too Many Requests` এরর খাবে)।
