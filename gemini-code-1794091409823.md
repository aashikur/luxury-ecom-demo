# Project Blueprint: Luxury Garments E-Commerce Master Boilerplate (v1.0)

## 1. Project Overview & Business Goal
A 100% Config-Driven, DRY E-Commerce Master Boilerplate built with **Next.js (App Router)**, **MongoDB**, and **Cloudinary**, specifically engineered for Bangladesh clothing/food/gadgets, streetwear, and luxury apparel brands.

* **Core Objective:** Launch a new client's custom-branded e-commerce website in **under 24 hours** without modifying core source code.
* **Deployment Model:** **1 Master Git Repository -> Deployed per Client** (Each client uses their own Domain, MongoDB Atlas URI, and Cloudinary credentials via `.env`).
* **Zero-Hardcode Rule:** Brand name, logo, colors, fonts, hero banners, delivery fees, and Meta Pixel IDs are **never** hardcoded. Everything is dynamically injected from the `StoreConfig` collection in MongoDB.
* **1-Click Global Update Strategy:** Because all client-specific branding and feature entitlements live in MongoDB, the codebase remains identical across all clients. Bug fixes and new features pushed to the `upstream/main` repository can be pulled into any client deployment with zero merge conflicts.

---

## 2. Tech Stack & Core Packages
* **Framework:** Next.js (App Router, Server Components, Server Actions) + TypeScript
* **Database:** MongoDB + Mongoose (with cached Singleton connection + Next.js `unstable_cache` / `revalidateTag`)
* **Styling & Dynamic Theme:** Tailwind CSS + CSS Custom Variables (`--bg`, `--surface`, `--fg`, `--accent`) + Shadcn UI + Lucide Icons
* **Media & Image Pipeline:** 
  * Client-side optimization: `browser-image-compression` (converts raw uploads to `image/webp` in browser prior to upload)
  * Cloud Storage: `cloudinary` SDK (auto-deletes old assets using `publicId` on update/delete)
* **State & Forms:** React Context + `localStorage` (Guest Cart), `react-hook-form` + `zod` (Validation)

## 3. Scope Boundaries (MVP vs. Out of Scope)

### IN SCOPE (Version 1.0)
1. **Dynamic Brand & Theme Engine:** Change Logo, Dark/Light Luxury Mode, Primary Accent Color, Fonts, and Layout Variants from DB.
2. **Pricing Tier Feature Switchboard:** Super-Admin UI to toggle paid features ON/OFF per client (`capiEnabled`, `abandonedCartEnabled`, `courierBookingEnabled`, `fraudCheckEnabled`, `advanceDeliveryEnabled`).
3. **Client-Side WebP Image Uploader:** Single DRY uploader component compressing images to ~150KB WebP before uploading to Cloudinary.
4. **Dynamic Hero Banner Manager:** Upload desktop/mobile banners, headings, CTA links, and toggle active status.
5. **Garments Catalog & SKU Matrix:** Products with Size variants (`S, M, L, XL, XXL`), individual stock per size, and an interactive Size Guide (Chest/Length/Shoulder in inches).
6. **1-Page Bangladesh COD Checkout:** Zero-login guest checkout (Name, 11-Digit BD Phone, Address, Inside/Outside Dhaka delivery zone).
7. **Auto-Lead Capture (Abandoned Cart):** Automatically captures draft `INCOMPLETE` orders as soon as a valid 11-digit BD phone number (`^01[3-9]\d{8}$`) is entered.
8. **Courier & Marketing Integrations (Gated):** Meta Pixel + Server-Side CAPI event deduplication, Steadfast 1-Click Courier booking, and BD Courier Fraud/Success ratio check.

### OUT OF SCOPE (Strictly Excluded to Prevent Over-Engineering)
* Customer Account Login/Registration (100% Guest Checkout by Phone Number).
* Drag-and-Drop Page Builder (Use clean pre-built layout variants instead).
* Multi-vendor marketplace capabilities.
* Complex international tax/shipping calculators.

## 4. Database Schema Specification (4 Collections Only)

### 4.1 `StoreConfig` (Singleton Document)
* `branding`: `{ storeName, tagline, logo: { url, publicId }, favicon: { url, publicId }, themeMode: 'DARK' | 'LIGHT', colors: { bg, surface, fg, muted, accent }, fonts: { heading, body }, heroVariant: 'SPLIT' | 'CENTER' }`
* `banners`: `[{ desktopImage: { url, publicId }, mobileImage: { url, publicId }, title, subtitle, buttonText, buttonLink, isActive, order }]`
* `logistics`: `{ phone, whatsapp, address, insideDhakaFee, outsideDhakaFee, freeShippingThreshold }`
* `tracking`: `{ metaPixelId, metaCapiToken, ga4Id }`
* `features`: `{ capiEnabled: boolean, abandonedCartEnabled: boolean, courierBookingEnabled: boolean, fraudCheckEnabled: boolean, advanceDeliveryEnabled: boolean, couponEnabled: boolean }`

### 4.2 `Category`
* `name`, `slug`, `image: { url, publicId }`, `isActive`, `order`

### 4.3 `Product`
* `title`, `slug`, `description`, `category` (Ref: `Category`), `basePrice`, `discountPrice`
* `images`: `[{ url, publicId }]`
* `variants`: `[{ sku, size: 'S' | 'M' | 'L' | 'XL' | 'XXL', colorName?, colorHex?, stock: number }]`
* `sizeChart`: `[{ size: string, chest: string, length: string, shoulder?: string }]`
* `isFeatured: boolean`, `isActive: boolean`

### 4.4 `Order`
* `orderNumber`: Unique readable ID (e.g., `ORD-10042`)
* `customer`: `{ name, phone, address, deliveryZone: 'INSIDE_DHAKA' | 'OUTSIDE_DHAKA', note? }`
* `items`: `[{ productId, title, image, size, quantity, unitPrice }]`
* `financials`: `{ subtotal, deliveryFee, discount, totalAmount, isAdvancePaid: boolean }`
* `status`: `'INCOMPLETE' | 'PENDING' | 'CONFIRMED' | 'SHIPPED' | 'DELIVERED' | 'CANCELLED' | 'RETURNED'`
* `courier`: `{ provider: 'STEADFAST' | 'PATHAO' | null, consignmentId?, trackingCode?, status? }`

## 5. Folder Structure & DRY Architecture Rules

```text
src/
├── app/
│   ├── (storefront)/           # Customer-facing pages (Home, Product [slug], Checkout, Order Success)
│   ├── admin/                  # Client Merchant Dashboard (Orders, Products, Categories, Banners & Settings)
│   ├── super-admin/            # Developer Control Plane (Feature Toggles, Theme Config, Kill-Switch)
│   └── api/
│       ├── upload/             # Cloudinary upload & delete endpoint
│       ├── config/             # StoreConfig CRUD + revalidateTag('store-config')
│       ├── products/           # Product & Category CRUD
│       ├── orders/             # Order placement, Abandoned Cart capture, Status updates

├── components/

│   ├── storefront/             # Navbar, CartDrawer, HeroVariants, ProductCard, SizeChartModal
│   ├── admin/                  # OrderTable, ProductForm, BannerManager

│   ├── db.ts                   # Cached Mongoose connection singleton

│   ├── cloudinary.ts           # Server-side Cloudinary upload/destroy helpers
│   ├── image-compression.ts    # Client-side browser-image-compression WebP helper
│   └── api-handler.ts          # DRY wrapper for API routes (DB connect + Error handling + Feature guard)

    ├── StoreConfig.ts
    ├── Category.ts
    ├── Product.ts
